### 1. ✅ index.html - Полностью переписан

- **Валидация**: проверка суммы > 0, trim строк, понятные ошибки
- **Агрегация на клиенте**: подсчёт суммы за месяц

- **Синхронизация**: с fallback на no-cors, отправка ID для дедупликации

- **Кнопки категорий**: визуальная обратная связь, автозаполнение поля

### 3. ✅ sw.js - Service Worker с версионированием
- **Cache-first стратегия**: оффлайн после первой загрузки
- **Versioning**: `budget-v2`, автоочистка старых кэшей
- **Activate event**: cleanup + clients.claim()
- **Smart caching**: игнорирование внешних API, только GET запросы
- **Fallback**: возврат index.html для SPA navigation

## 🧪 Как протестировать

### На Mac (прямо сейчас!)
```bash
cd /Users/tiurnikov/Documents/budget-tracker
python3 -m http.server 8000
```
Откройте: http://localhost:8000

### На iPhone через локальную сеть
1. Узнайте IP: `ifconfig | grep "inet " | grep -v 127.0.0.1`
2. Откройте в Safari: `http://ВАШ_IP:8000`

⚠️ Service Worker работает только через HTTPS (кроме localhost)
