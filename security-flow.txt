└─────────────────────────────────────────────────────────────┘

1. РАЗМЕЩЕНИЕ НА GITHUB PAGES
   ┌──────────────────────┐
   │   GitHub Repository  │  ← index.html, app.js, sw.js
   │   (публичный код)    │    БЕЗ СЕКРЕТОВ ✅
   └──────────────────────┘
            │
            │ git push
            ▼
   ┌──────────────────────┐
   │   GitHub Pages       │  ← Хостинг с HTTPS
   │   your-site.github.io│    Автоматический SSL ✅
   └──────────────────────┘


2. ПОЛЬЗОВАТЕЛЬ ОТКРЫВАЕТ САЙТ
   ┌──────────────────────┐
   │   Safari (iPhone)    │  ← Загружает HTML/CSS/JS
   │   или Chrome (Mac)   │    Видит пустую форму
   └──────────────────────┘
            │
            │ Пользователь вводит настройки
            ▼
   ┌──────────────────────┐
   │   localStorage       │  ← Сохраняет:
   │   (браузер)          │    • syncUrl: "https://..."
   │                      │    • syncToken: "abc123..."
   │   ПРИВАТНО ✅        │    • Видит только этот браузер
   └──────────────────────┘


3. ДОБАВЛЕНИЕ РАСХОДА
   ┌──────────────────────┐
   │   Пользователь       │  ← Вводит: Кофе, 300₽
   └──────────────────────┘
            │
            ▼
   ┌──────────────────────┐
   │   IndexedDB          │  ← Сохраняет локально:
   │   (браузер)          │    • id: uuid
   │                      │    • title: "Кофе"
   │   ПРИВАТНО ✅        │    • amount: 300
   └──────────────────────┘    • synced: false


4. СИНХРОНИЗАЦИЯ (при нажатии кнопки)
   ┌──────────────────────┐
   │   app.js             │
   │   syncExpenses()     │
   └──────────────────────┘
            │
            │ 1. Читает из localStorage
            │    token = "abc123..."
            │    url = "https://script.google.com/..."
            │
            │ 2. Берёт несинхронизированные из IndexedDB
            │
            │ 3. Формирует запрос:
            ▼
   ┌──────────────────────┐
   │   HTTPS запрос       │  ← POST с телом:
   │   (зашифрованный)    │    {
   │                      │      "token": "abc123...",
   │   БЕЗОПАСНО ✅       │      "rows": [{...}]
   └──────────────────────┘    }
            │
            │ Передача по HTTPS
            │ (никто не может прочитать токен)
            ▼
   ┌──────────────────────┐
   │   Apps Script        │
   │   doPost(e)          │
   └──────────────────────┘
            │
            │ 1. Парсит данные
            │ 2. ПРОВЕРЯЕТ ТОКЕН ✅
            ▼
   ┌──────────────────────┐
   │   if (token ≠ SECRET)│  ← Если токен неверный:
   │   ❌ ОТКЛОНИТЬ       │    • return error
   │                      │    • sleep 2 сек (anti brute-force)
   └──────────────────────┘    • НЕ добавлять в таблицу
            │
            │ Токен верный ✅
            ▼
   ┌──────────────────────┐
   │   Google Sheets      │  ← Добавляет строки:
   │   "Расходы"          │    • Проверка дубликатов (по ID)
   │                      │    • Добавление новых
   │   ЗАЩИЩЕНО ✅        │    • return { ok: true, added: N }
   └──────────────────────┘


5. ЧТО ВИДИТ ЗЛОУМЫШЛЕННИК?
   ┌──────────────────────┐
   │   Посторонний        │  ← Открывает ваш сайт
   │   пользователь       │
   └──────────────────────┘
            │
            │ View Source / DevTools
            ▼
   ┌──────────────────────┐
   │   Видит:             │
   │   • HTML/CSS/JS код  │  ← Исходный код
   │   • Пустую форму     │  ← Может ввести СВОИ настройки
   │                      │
   │   НЕ видит:          │
   │   ❌ Ваш токен       │  ← localStorage изолирован!
   │   ❌ Ваш URL         │  ← Не в коде
   │   ❌ Ваши расходы    │  ← IndexedDB изолирован!
   └──────────────────────┘


6. ПОПЫТКА АТАКИ БЕЗ ТОКЕНА
   ┌──────────────────────┐
   │   Злоумышленник      │  ← Узнал URL Apps Script
   └──────────────────────┘    (например, перехватил трафик)
            │
            │ Пытается отправить данные
            ▼
   curl -X POST https://script.google.com/.../exec \
     -d '{"rows": [{"title": "Взлом"}]}'
            │
            ▼
   ┌──────────────────────┐
   │   Apps Script        │
   │   doPost(e)          │
   └──────────────────────┘
            │
            │ Проверяет токен
            ▼
   ┌──────────────────────┐
   │   data.token         │  ← undefined или null
   │   ≠                  │
   │   SECRET_TOKEN       │  ← "abc123..."
   │                      │
   │   ❌ ОТКЛОНЕНО       │  ← return { ok: false }
   └──────────────────────┘    + sleep 2 сек


7. ПОПЫТКА BRUTE-FORCE
   ┌──────────────────────┐
   │   Злоумышленник      │  ← Пытается угадать токен
   └──────────────────────┘
            │
            │ for token in ["aaa", "bbb", "ccc", ...]:
            ▼
   ┌──────────────────────┐
   │   Apps Script        │  ← При каждой неудаче:
   │   Utilities.sleep()  │    • sleep 2 секунды
   │                      │    • Логирует в "Выполнения"
   │   ЗАЩИТА ✅          │    • Слишком медленно для перебора
   └──────────────────────┘    • Видно в логах


ВЫВОД:
======
✅ Код на GitHub Pages не содержит секретов
✅ Токен хранится только в браузере пользователя
✅ localStorage изолирован по доменам
✅ HTTPS шифрует передачу токена
✅ Apps Script проверяет токен на каждый запрос
✅ Без токена доступ к таблице невозможен
✅ Brute-force защищён задержкой
✅ Дедупликация по UUID
