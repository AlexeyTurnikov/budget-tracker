## 🧪 Как проверить локально:

1. Откройте файл `test-buttons.html` в браузере
2. Нажмите на кнопки категорий
3. Проверьте что значение появляется в поле "Название"
4. Проверьте консоль (F12) - должны быть логи

## 🌐 Как проверить на GitHub Pages:

1. Откройте: https://alexeyturnikov.github.io/budget-tracker/
2. **Обязательно очистите кеш**: Cmd + Shift + R (Mac) или Ctrl + Shift + R (Windows)
3. Откройте консоль браузера: Cmd + Option + J (Mac) или F12 (Windows)
4. Проверьте логи в консоли:
   - "Элементы инициализированы: ..."
   - "Найдено кнопок категорий: 6"
5. Нажмите на кнопку категории - должны увидеть:
   - "Нажата категория: ..."
   - Значение в поле "Название"

## 📱 Если не работает:

1. **Очистите кеш полностью**:
   - Chrome: Settings → Privacy → Clear browsing data → Cached images
   - Safari: Develop → Empty Caches
   
2. **Режим инкогнито**:
   - Откройте сайт в приватном режиме
   
3. **Подождите 2-3 минуты**:
   - GitHub Pages может обновляться с задержкой
